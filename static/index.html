{name} 은 수신자 이름으로 바뀝니다.
링크: 본문에서 링크를 걸 글자를 드래그로 선택하고 링크 넣기를 누른 뒤 주소를 입력하세요. 본문에 {link:보일 글자|https://주소} 가 들어가고, 받는 사람에게는 그 글자가 눌리는 링크로 보입니다. 본문에 그냥 적은 https:// 주소도 링크가 됩니다.
예: 300 (픽셀) 또는 50%
이미지를 고른 뒤, 본문에서 넣을 위치에 커서를 두고 아래 이미지 이름 버튼을 누르세요. 본문에 {image:파일명} 이 들어가고, 그 자리에 이미지가 보이게 발송됩니다. 여러 장을 고를 수 있고, 같은 이미지를 여러 번 넣어도 됩니다.
크기는 위 너비 칸에 적고 버튼을 누르거나, 본문에서 직접 {image:파일명|300} (300픽셀), {image:파일명|50%} (본문 폭의 절반) 처럼 고치면 됩니다. 비워 두면 원본 크기(화면보다 크면 화면에 맞춤)입니다.
